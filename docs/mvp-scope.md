# MVP 范围（问题 8）

目标：做出 **真正有用的自动估值管家**，而不是「每天手填价格的计算器」。

---

## MVP 一句话

> 用户录入交易与手动账户；App 每个交易日自动取价/净值，算出总资产、当日/累计收益、分红与费用、占比，并支持股票与基金区间收益对比。

---

## 必须有（P0）

### 1. 交易与持仓

- 标的搜索/添加：A 股、港股、美股、ETF、场外基金（代码 + 名称）  
- 交易类型：买入/卖出、申购/赎回、现金分红、费用、拆合股（可先合并进「公司行为」手动）  
- 由流水生成当前持仓（数量、成本）  
- 支持多账户（可选简单版：默认一个「默认账户」）

### 2. 自动行情（日频）

- 关注标的日终价 / 基金净值自动刷新  
- 汇率自动刷新（USD、HKD → 本位币，默认 CNY）  
- 本地缓存；失败时沿用昨价并显示「数据未更新」  
- **用户无需每日手填价格**

### 3. 收益与资产视图

- 总资产（本位币）  
- 当日盈亏、累计盈亏  
- 收益拆解：价格变动 + 分红 − 手续费（能拆多少算多少，口径写清）  
- 资产占比：按资产类别、按标的  
- 持仓列表：市值、浮动盈亏、占比

### 4. 股票 vs 基金对比

- 选择两个标的或两个组合（如「股票仓」vs「基金仓」）  
- 同一区间、同一货币的累计收益率曲线/数字  
- 只展示历史对比，不给建议

### 5. 存款 / 理财（低成本）

- 手动账户：活期、定期、理财  
- 录入余额/本金/利率或当前估值  
- 计入总资产与占比  
- 估值过期提醒

### 6. 本地数据

- SQLite 持久化  
- 导出备份（JSON 或 CSV）  
- 无荐股相关模块

---

## 明确不做（MVP 内）

- 实时 Level-1 推送行情墙  
- 银行 API / 券商同步  
- 云同步与多用户登录（可后置）  
- 税务优化、IRS/个税报表  
- 期权、期货、加密货币（可进 Phase 2）  
- 任何预测与荐股

---

## 验收场景（Definition of Done）

1. **录入买入**：买入 1000 股某 A 股 + 佣金 → 持仓出现正确数量与成本  
2. **隔日打开**：不改价格 → 市值与盈亏随收盘价变化  
3. **基金申购**：录入份额 → 按最新净值估值  
4. **分红**：录入或同步现金分红 → 累计收益含分红  
5. **占比**：股票 + 基金 + 存款合计 100%  
6. **对比**：某 ETF 与某场外基金近 1 年收益率可对比  
7. **无网络兜底**：显示缓存价与陈旧标记，不丢本地账本  
8. **审查**：全 App 无荐股/预测文案

---

## 建议实现顺序

```
Week 1  数据模型 + 本地库 + 交易录入 + 持仓还原
Week 2  MarketDataProvider + 日终刷新 + 市值/盈亏
Week 3  资产占比 + 收益拆解 + 基金净值
Week 4  手动存款理财 + 股基对比 + 导出备份
```

（周次为示意，按实际节奏调整。）

---

## 什么叫「不是纯手动计算器」

| 纯手动计算器 | 本 MVP |
|---|---|
| 每天改现价 | 日终自动取价 |
| 只有总盈亏一个数 | 价差/分红/费用可追溯 |
| 基金靠手填净值 | 净值自动拉 |
| 外币不管汇率 | 自动汇率到本位币 |
| 存款另用便签 | 同一套总资产与占比 |

自动取价 + 交易事实沉淀，就是与计算器的本质区别。
