# 资产模型与收益口径

## 资产类别

- 银行存款、债券、基金、股票/ETF、外币储蓄、现金/其他 → **计入总资产**
- 负债 → **不计入总资产**，只参与净资产

```
总资产CNY = Σ 各类资产市值CNY
净资产CNY = 总资产CNY − 负债CNY
```

外币：`amountInCNY = amount × rateToCNY`。

## 手动资产（不接银行）

- 银行存款 / 外币储蓄：余额、利率、起息/到期、预计与已到账利息
- 债券：面值、成本、票面利率、到期日、最新估值
- 现金/其他、负债：余额 + 币种

## 收益构成

| 分量 | 是否算收益 |
|---|---|
| 本金变化（存入/取出） | 否 |
| 价格收益 | 是 |
| 利息 | 是 |
| 分红 | 是 |
| 手续费 | 是（从收益中扣除） |

```
累计收益 = 价格收益 + 利息 + 分红 − 手续费
```

股票/ETF/基金沿用交易流水与行情；基金/股基分红与手续费计入对应分量。
