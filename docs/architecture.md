# 架构与本地存储

对应问题 5–6：是否需要服务器；用户数据如何本地保存。

---

## 5. 是否需要服务器和后端？

### 结论（分阶段）

| 阶段 | 是否需要后端 | 理由 |
|---|---|---|
| **MVP（个人自用）** | **可以没有完整业务后端** | 持仓/交易全本地；行情可由客户端直连或极薄代理 |
| **多设备同步 / 上架** | 需要轻后端 | 同步、鉴权、Key 托管、合规行情转发 |
| **多人 SaaS** | 需要完整后端 | 账户体系、订阅、审计、授权行情 |

### MVP 推荐拓扑：本地优先 + 可选行情代理

```
┌─────────────────────────┐
│  Mobile / Desktop App   │
│  ┌───────────────────┐  │
│  │ SQLite（用户数据） │  │
│  │ 持仓·交易·快照    │  │
│  └───────────────────┘  │
│  ┌───────────────────┐  │
│  │ 估值引擎（本地）   │  │
│  └───────────────────┘  │
└───────────┬─────────────┘
            │ 日终拉行情（可选经代理）
            ▼
┌─────────────────────────┐
│  (可选) 极薄 Proxy      │
│  · 缓存日线/净值         │
│  · 隐藏 API Key          │
│  · 限流与降级            │
│  · 不存用户持仓          │
└─────────────────────────┘
```

### 什么时候「必须」上后端？

1. App Store / 多用户分发，且行情 Key 不能写进客户端  
2. 需要 iCloud/自建云同步多设备  
3. 要用付费授权行情且合同要求服务端转发  
4. 做家庭共享账本、权限协作  

**当前目标不需要这些 → MVP 可不建业务后端。**

### 客户端技术倾向（待选型会确认）

- **Flutter**：一套代码 iOS/Android，SQLite（drift/sqflite）成熟  
- **Expo/React Native**：同样可行；本地可用 expo-sqlite  
- **纯 Web PWA**：可行但本地持久化与后台拉取较弱，移动体验一般  

个人财富 App 优先 **原生壳 + 本地库**，而不是先做网站。

## 6. 用户数据如何本地保存？

### 存储选型

| 方案 | 适用 | 说明 |
|---|---|---|
| **SQLite**（推荐） | 主库 | 结构化交易、持仓、日快照、查询快 |
| 加密层（SQLCipher / 系统 Keychain 密钥） | 敏感增强 | MVP 可后置；先文件系统权限保护 |
| JSON 文件 | 仅配置/导出 | 不适合大量流水 |
| iCloud / 系统备份 | 系统级 | 依赖 OS 备份，非应用内同步 |

### 核心数据模型（草案）

```
Account          账户（券商、银行、现金口袋）
Instrument       标的元数据（代码、市场、类型、币种）
Transaction      交易流水（买/卖/申购/赎回/分红/费用/存取）
PositionSnapshot 日终持仓快照（数量、成本、市值、币种）
PriceBar         缓存的日行情/净值
FxRate           日终汇率
ManualValuation  手动账户估值记录（理财）
AppSettings      本位币、日切时区、隐私选项
```

### 交易驱动持仓（重要）

**不要让用户天天改「当前价」**；持仓数量由交易流水还原：

```
持仓数量 = Σ买入/申购 − Σ卖出/赎回 ± 拆合股调整
成本口径 = 移动平均 或 先进先出（MVP 选一种，推荐移动平均）
市值     = 数量 × 最新有效价（或净值）
浮动盈亏 = 市值 − 成本市值（口径需在文档写死）
已实现   = 卖出所得 − 对应成本 + 现金分红 − 费用
```

### 每日自动任务（本地）

1. 交易日结束后（或用户打开 App 时）拉取关注标的日终价/净值  
2. 拉汇率  
3. 生成 `PositionSnapshot`  
4. 计算当日盈亏、累计指标、占比  
5. 标记过期手动估值  

即使没有后端定时任务，**「打开 App / 下拉刷新 / 本地通知触发」** 也能完成个人场景的日更。

### 隐私与导出

- 默认不上传持仓与交易  
- 支持导出 CSV/JSON（用户自有备份）  
- 可选应用锁（系统生物识别）  
- 若未来同步：端到端加密或至少传输加密 + 服务端最小化

### 备份策略（MVP）

1. 导出文件到系统文件 / iCloud Drive / 网盘（用户主动）  
2. 依赖系统 App 备份  
3. 后期再做「加密同步后端」
