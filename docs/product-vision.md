# 产品愿景

## 一句话

个人财富的「记账 + 自动估值」工具：交易由用户录入，市值与收益由行情自动算。

## 目标用户

- 同时持有 A 股 / 港股 / 美股 / ETF / 场外基金 / 存款理财的个人投资者
- 愿意认真记交易，但不想每天手动改价格
- 需要看清「赚了多少、钱在哪、股票 vs 基金谁更好」，不需要别人告诉他买什么

## 核心体验闭环

```
录入持仓与交易
      ↓
日终自动取价 / 净值 / 汇率
      ↓
计算：当日盈亏 · 累计收益 · 分红 · 手续费 · 资产占比
      ↓
对比：个股/ETF vs 基金（同一时间窗口、同一货币口径）
```

## 成功标准（MVP）

1. 录入一笔买入后，次日无需改价即可看到持仓市值与浮动盈亏  
2. 累计收益能拆开：价差 + 分红 − 手续费  
3. 资产页能按类别/标的看到占比  
4. 任意两只（或一类 vs 一类）可对比区间收益率  
5. 全程无荐股、无买卖提示、无预测

## 产品原则

1. **交易是事实，价格是行情** — 用户管交易，系统管市价  
2. **日频够用** — 个人财富复盘以日终为主，实时报价是增强项  
3. **可解释** — 每个收益数字都能追溯到交易与取价来源  
4. **本地优先** — 持仓与交易默认不出设备  
5. **克制** — 功能少但算得准，优于功能多但口径混乱
