# 明确不做（问题 7）

本产品是 **个人资产记账与自动估值**，不是投顾、不是交易终端。

## 永久非目标（除非产品定位变更）

| 类别 | 具体内容 |
|---|---|
| 荐股 | 热股榜、老师推荐、跟单 |
| 买卖建议 | 「建议加仓/减仓」「目标价」「操作信号」 |
| 价格预测 | AI 预测涨跌、走势召唤、概率预测 |
| 社交晒单 | 收益排行榜刺激攀比（可后续再议，默认不做） |
| 代客下单 | 交易通道、一键买卖 |

## 文案与交互约束

1. 任何收益展示旁可放免责声明：**数据仅供记录与统计，不构成投资建议**  
2. UI 不出现「推荐」「看好」「看空」「抄底」「逃顶」等措辞  
3. 对比功能只做 **历史已实现/区间收益率对比**，不输出「该买哪个」  
4. 通知只用于：行情刷新失败、净值已更新、手动估值过期、备份提醒 —— 不做价格异动荐股推送

## 允许的「智能」边界

| 允许 | 不允许 |
|---|---|
| 自动取价、自动汇总 | 预测明日涨跌 |
| 分红/费用归因 | 「因为波动大建议卖出」 |
| 同类历史收益对比图表 | 「跑输了所以换成另一只」的建议文案 |
| 资产占比可视化 | 智能再平衡方案（早期） |

## 评审检查清单

发版或加功能前自问：

- [ ] 这个功能是否在帮用户 **记录或看清已有资产**？  
- [ ] 是否隐含 **叫用户去买/卖**？  
- [ ] 是否依赖 **预测未来价格**？  

若后两项为是 → 不做。
