# iOS 实现说明

## 打开工程

```bash
open WealthKeeper.xcodeproj
```

在 Xcode 中选择自己的 Development Team，用 iPhone 模拟器或真机运行。

## 已实现

1. **本地 SwiftData**：标的、买卖/分红/手续费/拆合股流水、持仓缓存、行情缓存、公司行为、设置  
2. **手动录入交易**：A 股 / 港股 / 美股 / 基金  
3. **联网日终行情**：  
   - A 股、场外基金净值 → 东财（A 股失败时 Yahoo 兜底）  
   - 港股、美股 → Yahoo Finance  
   - 汇率 USD/HKD → Yahoo  
   - 分红/拆股（美港）→ Yahoo events，可自动导入流水  
4. **收益计算**：移动平均成本；总资产、今日盈亏、浮动、已实现、分红、手续费、资产占比  

## 使用路径

1. 「交易」或资产页「+」录入买入  
2. 点左上角刷新，拉取收盘价/净值/汇率  
3. 资产页查看市值与盈亏  

## 口径

- 浮动盈亏 = 市值 − 持仓成本（成本含买入手续费）  
- 已实现 = 卖出盈亏 + 现金分红 − 独立手续费  
- 外币按设置中本位币汇率折算（默认 CNY）  

## 不做

荐股、买卖建议、价格预测（见 `docs/non-goals.md`）。
