# 汇率数据说明（大陆用户）

## 结论

| 来源 | 大陆可达性 | 用途 |
|---|---|---|
| **东财外汇** `push2delay.eastmoney.com` | 高（与 A 股同源） | **主路径** |
| **新浪财经** `hq.sinajs.cn` | 高 | **回落** |
| Yahoo Finance FX | 常超时/不稳定 | **不再作为汇率主路径** |

Yahoo 对大陆网络并不保证可用（DNS/墙/限流均常见），因此汇率改为东财 → 新浪，与收盘价刷新同一入口同步更新。

## 口径

- 拉取 `USD/CNH`、`HKD/CNH`（近似兑人民币）
- 再按用户本位币换算：`1 外币 = rate 本位币`
- 随资产页「刷新」与标的行情一起更新，并写入 `lastFXRefresh` / `fxSource`
